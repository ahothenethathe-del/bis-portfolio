# Personal BIS Portfolio Website

## Files
- `index.html` — website content and sections
- `style.css` — colours, layout and mobile-responsive styling
- `script.js` — mobile navigation menu and automatic footer year

## Run on your computer
1. Extract the ZIP file.
2. Open the `bis_personal_portfolio` folder in Visual Studio Code.
3. Install the **Live Server** extension (optional but helpful).
4. Right-click `index.html` and select **Open with Live Server**. You can also double-click `index.html` to open it in a browser.

## Personalise before publishing
- Search for `Your Name` and replace it with your preferred professional name.
- Replace `YN` with your initials.
- Update the about section and skills so they accurately describe you.
- Replace sample email, GitHub and LinkedIn links.
- Add real screenshots, GitHub links and results for projects you have actually built.
- Change the education details if needed.
- The example projects are labelled planned/in progress. Update their status honestly.

## Mobile testing
In Chrome, press `F12`, select the device toolbar icon, and test common phone sizes. Check that all links work, text is readable, and no section causes horizontal scrolling.

## Publish free with GitHub Pages
1. Create/sign into a GitHub account.
2. Create a repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload the three website files to the repository's root.
4. Open the repository's **Settings → Pages**.
5. Choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
6. Wait for the site to publish and visit `https://YOUR-USERNAME.github.io`.

This is a static portfolio: it does not have a database or a server-side contact form. The email button opens the visitor's email app.
